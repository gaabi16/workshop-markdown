## Introduction

Markdown is a lightweight markup language that you can use to add formatting elements to plaintext text documents.

## Features

Some cool features you can use in Markdown:

* **Bold text**
* *Italic text*
* `Inline code`
* [Links](https://www.markdownguide.org)
* Images
* Lists
* Tables

## Code Example

Here's a simple Python snippet:

```python
def greet(name):
    return f"Hello, {name}!"

print(greet('World'))
```
